# Sadevahti / ForecastApp

Sadevahti on Vue 3:lla ja Vuetifyllä rakennettu sade-ennustesovellus. Sovellus hakee paikkakuntia Open-Meteon Geocoding API:sta ja näyttää valitun paikkakunnan 7 päivän sade-ennusteen Open-Meteon Forecast API:n avulla.

## Ominaisuudet

- Etusivu navigointikorteilla
- Paikkakuntahaku Open-Meteo Geocoding API:lla
- London, United Kingdom latautuu oletuksena
- 7 päivän sade-ennuste
- Päivittäinen sadesumma
- Sateen todennäköisyys
- Sadetunnit
- Responsiivinen käyttöliittymä
- Vue Router -reititys
- Pinia-tilanhallinta

## Teknologiat

- Vue 3
- Vuetify 3
- Vue Router
- Pinia
- Vite
- Open-Meteo API
